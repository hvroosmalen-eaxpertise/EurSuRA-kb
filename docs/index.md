# EurSuRA Knowledge Base

The **European Sustainability Reporting and Assessment (EurSuRA) Knowledge Base** is an encyclopaedic repository of standards, directives, frameworks, and reports relating to sustainability reporting in the European Union and internationally.

## Scope

This knowledge base covers:

- **ESRS** — European Sustainability Reporting Standards, developed by EFRAG under the mandate of the European Commission
- **CSRD** — Corporate Sustainability Reporting Directive (EU) 2022/2464
- **EU Taxonomy** — Regulation (EU) 2020/852 on sustainable finance classification
- **UN SDGs** — United Nations Sustainable Development Goals (2015–2030)
- **GRI** — Global Reporting Initiative sustainability disclosure standards
- **TCFD** — Task Force on Climate-related Financial Disclosures recommendations

## How to Use This Knowledge Base

Navigate using the tabs above. The **Glossary** contains all defined terms. The **Cross-Reference Matrix** maps relationships between standards and frameworks. The **Models** section contains derived semantic models and concept maps generated from the knowledge base content.

## Contributing

New documents are ingested via the automated pipeline. Drop PDF source documents in the `pipeline/inbox/` folder and run `ingest.py`. Each article follows the writing and tagging rules defined in the shared framework.
